# 20 上限 P0：執行與交接

日期：2026-10-07。狀態：P0 完成；GUI 上限仍為 10／8／6，P1–P8 未實作。

## 修正的問題

最小案例是預設獨棟 5×3、4 上層、種子 1 的 `1F-04` 與 `1F-05`：兩間店面沒有室內門，直接從街面入口進出。將它們合併成臥室，街面入口與歸屬仍完整保留，但舊 `checkPlan` 只把房型叫 `shop` 的房間列為街道入口，因此誤報「臥室 merged-1 走不到」。單間店面改成其他用途也有同樣問題。

修正在 `src/plan.ts` 的可達性檢查：街道入口須是一樓房間實際擁有、且雙向歸屬吻合的 `door`／`shop` 開口。房型名稱不影響入口存在。沒有外部入口的內部房間改名「店面」、上層窗改標成店面開口，仍會被判為不可達。樓梯與門口大廳的既有起點規則保留。

沒有修改合併幾何或新增門洞，也沒有放寬結構牆保護。新增回歸驗證入口保留、改名不產生入口、入口移除後確實不可達，以及上層開口不算街道入口。

## 檢查與基線入口

| 指令 | 用途 |
|---|---|
| `npm run check:rooms` | 房型、合併、門窗參照、凹輪廓、復原／重套與 pointer／GUI 回歸 |
| `npm run check:plans` | 11 組舊配置基線＋完整 25,920 組生成平面矩陣 |
| `npm run check:plans -- --baseline-only` | 只比對參數、結構、數量及完整平面雜湊 |
| `npm run check:plans -- --json /private/tmp/plan-checks.json` | 保存矩陣失敗摘要／分類與戶數統計；失敗仍以非零 exit code 結束 |
| `npm run bench:plans -- --json /private/tmp/plan-benchmark.json` | 六個固定場景的 CPU 計時與可重現性；預設暖機 5、樣本 30 |

`src/planChecks.ts` 提供共用場景枚舉及報告；主控台 `planCheckAll` 和 `check:rooms -- --plans` 均使用同一實作。瀏覽器保留 `[種子], [戶數模式]` 呼叫方式及原報告欄位，另增加 `byMode`。CLI 採 `defaultParams()`；瀏覽器採目前非矩陣參數，兩者的背景參數不同時應先對齊再比較。

`scripts/baselines/plans-v1.json` 是在修改前、來源 `99b2871` 擷取的基線。包含完整原始預設參數、11 組代表場景的結構快照、數量與完整平面 SHA-256；涵蓋三種建築、斜切、最小／最大舊尺寸、高窗宴會廳、均一樓高、種子與強制戶數。驗證入口不會自動更新基線。

## CPU 效能基線

環境：Apple M3 Pro，macOS arm64，Node v25.2.1，Vite SSR。每場景暖機 5 次、30 個樣本。原始資料：[P0效能基線.json](P0效能基線.json)。

| 場景 | 房間數 | 平面含檢查 p50 | 平面含檢查 p95 | 生成資料＋平面 p95 |
|---|---:|---:|---:|---:|
| 預設 5×3、4 上層 | 78 | 1.282 ms | 1.632 ms | 2.291 ms |
| 舊最大獨棟 10×8、6 上層 | 428 | 17.301 ms | 29.089 ms | 29.680 ms |
| 提案獨棟 20×20、20 上層 | 2,587 | 256.839 ms | 261.370 ms | 265.290 ms |
| 極小獨棟 2×2、20 上層 | 66 | 0.570 ms | 0.693 ms | 0.997 ms |
| 連棟預設正面、側面 20、20 上層 | 240 | 1.701 ms | 3.169 ms | 3.538 ms |
| 連棟正面 20、depth 60、20 上層 | 1,883 | 47.693 ms | 75.849 ms | 77.252 ms |

`generateBuilding` 使用只回傳零件 key 的 PartIndex，因此計的是配置資料，不含實際 kit mesh。平面時間包含 `checkPlan`，不含室內、家具、標籤、瀏覽器及 GPU，不能拿此數據當完整重建或畫面 FPS。

大型場景仍是舊算法，沒有中庭、採光井、電梯與完整高層動線檢查；舊 `issues === 0` 不代表新要求通過。20×20×20 的 p95 仍高於 100 ms 目標。連棟 `baysY:20` 實際長度仍是預設 `depth:12`，這是待 P1 定義尺寸語意的已知情況。

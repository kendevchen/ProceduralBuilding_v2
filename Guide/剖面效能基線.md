# 剖面效能基線

日期：2026-10-06。優化前程式版本：`3afe56c`，分支 `feature/room-editor`。

## 量測方式

Chrome 前景頁面，預設 5×3、4 上層、種子 1；寫實室內、陰影及後製開啟、像素比 1.25、後製 MSAA 2x。暫時量測程式放在系統暫存目錄，透過獨立 Vite 測試頁注入，未修改專案渲染程式。

暖機 90 幀，再取樣 180 幀；FPS 為畫面更新間隔平均值的倒數，非 GPU timer。renderer.info 在整個後製幀前重設，統計包含陰影與後製繪製。外觀／水平剖面使用相同相機；展開使用展示視角，因此跨模式比較包含視角及畫面內容差異。

## 第一輪結果

視窗 1313×996、drawing buffer 1641×1245。

| 情境 | FPS | 幀間隔中位數 ms | 完整幀 draw calls | 提交三角形 |
| --- | ---: | ---: | ---: | ---: |
| 外觀 | 85.6 | 11.9 | 255 | 169,906 |
| 水平 50% | 26.3 | 37.5 | 326 | 1,005,798 |
| 展開全覽 | 11.1 | 89.9 | 703 | 2,606,708 |
| 展開、隱藏家具 | 16.3 | 60.9 | 620 | 208,378 |
| 展開、關閉陰影 | 11.4 | 88.0 | 443 | 1,355,365 |

展開關閉後製測得 7 FPS，但同時切換到 canvas 直接渲染及不同抗鋸齒路徑，不能解讀為純後製成本。

解析度比較使用相同 1313×940 視窗：像素比 0.75 時 21.3 FPS，恢復 1.25 時 11.2 FPS；兩者提交三角形同為 2,606,708。

## 材質對照與限制

同一展開場景、1313×996 視窗：白模 18.8 FPS／52.9 ms／2,602,770 三角形；恢復寫實後 10.0 FPS／99.8 ms／2,606,708 三角形。幾何差約 0.15%，支持室內程序化材質具有顯著成本。白模仍保留部分家具材質，且有少量幾何與 draw calls 差異，並非完全隔離所有 shader 的測試。

下一步先對 `src/finishes.ts` 的牆面／地板噪聲與花紋計算做小範圍優化，逐項比較畫質與幀時間。家具分批、剖面剔除與減面另行處理；尚未取得 GPU timer、長時間或不同硬體結果。

## 第一輪材質優化

同一天、相同展開場景與 1313×996 視窗，優化前重新取樣為 10.0 FPS／100.0 ms（幀間隔中位數）。噪聲改為共用自製 256×256 單通道貼圖，保留三次插值曲線，由硬體插值與 mipmap 處理細紋；地板編譯排除牆面花紋分支，保留樓梯間白色大理石地板。主花紋與幾何維持，細紋分布因週期噪聲及濾波略有變化。

優化初測為 27.0／27.1 FPS；補齊樓梯間白色大理石地板後再測為 26.2 FPS，中位數 42.8 ms、P95 54.3 ms。703 draw calls、2,606,708 三角形保持一致；普通水平半剖另測得 31.7 FPS（原基線 26.3）。此結果屬本機、固定場景的畫面更新效能，不是 GPU timer 或跨裝置保證。七種展開回歸、shader 編譯與建置通過，已檢查全覽及放大後的材質外觀。
